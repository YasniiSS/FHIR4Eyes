Capability Statement

The FHIR4Eyes Capability Statement describes the expected capabilities of a FHIR server exchanging ophthalmic data under this guide: the resource types it supports, the profiles it is expected to declare, and the search parameters it should support for each of them.

Search Parameters

The following search parameters are defined by this guide, in addition to those defined in the FHIR standard (see the search parameter registry). Most of them make the laterality pattern searchable: they search the BodyStructure referenced from bodySite (see General Guidance).

The search parameters below SHALL NOT be interpreted on their own as a list of search requirements for a server. See the Capability Statement for the expected server behaviour.

Resource Code Search parameter Searches on
Condition eye ConditionEye Laterality (bodySite → BodyStructure)
DiagnosticReport imaging-study DiagnosticReportImagingStudy DiagnosticReport.imagingStudy

ImagingStudy modality ImagingStudyModality ImagingStudy.series.modality
