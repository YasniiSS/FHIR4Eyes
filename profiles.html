This page lists every profile defined in FHIR4Eyes Core, grouped by clinical domain. Each profile page contains the narrative description and design decisions for that profile, followed by its formal definition. For the clinical motivation behind each profile, see Use Cases; for the patterns shared across profiles (laterality, panels, components), see General Guidance; for terminology, see Terminology. All example instances are listed on the Examples page.

Within each domain, profiles are listed in the order they typically appear in a clinical encounter: the medical order, the diagnosis (when already known), the procedure or observation performed, any imaging study involved, the resulting diagnostic report, and finally the treatment plan.

Profiles pending clinical validation

The following profiles remain lower priority and are deliberately left undesigned in this guide until they can be reviewed with an ophthalmologist colleague, rather than being modeled speculatively:

  • Goal (intraocular pressure target)
  • Biomicroscopy
  • Gonioscopy
  • Fundus examination
  • And others, to be identified as this guide develops further

Not every possible ophthalmic examination needs a dedicated profile in this guide. A profile is only warranted where the examination has a structural need beyond what a simple Observation bound to the terminology already defined in Terminology can represent (for example, a panel, as with TensionCurve, or a multi-component exam, as with StrabismusExam). Examinations that fit the simple pattern do not require their own profile, and are already covered by the general terminology strategy.
