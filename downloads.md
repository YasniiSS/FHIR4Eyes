## Downloads

### Package file

The following package file includes an NPM package used by many FHIR tools. It contains all the profiles, value sets, code systems, search parameters and examples defined in this version of the guide. It should be the first choice when generating implementation artefacts or validating resources against this guide.

* [Package](package.tgz)

See [validating FHIR resources](http://hl7.org/fhir/R4/validation.html) for how to use these artefacts to validate instances.
